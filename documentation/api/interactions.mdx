Utilisez cet endpoint pour enregistrer quand un utilisateur interagit avec le contenu d'un autre utilisateur sur XERA1. Chaque appel que vous effectuez crée une entrée dans le journal d'interactions et, comme effet secondaire, déclenche le recalcul automatique des métriques de rétention du créateur cible et du score d'affinité du spectateur envers ce créateur : le moteur de recommandation reste ainsi à jour sans aucun travail supplémentaire de votre part.

## Endpoint

```text
POST https://xera1.xyz/api/app/interaction/track
```

## Authentification

<Note>
  Cet endpoint nécessite un jeton de session valide. Incluez-le dans chaque requête en tant que jeton Bearer dans l'en-tête `Authorization`.
</Note>

```text
Authorization: Bearer <session_token>
```

## Corps de la requête

<ParamField body="interaction_type" type="string" required>
  Le type d'interaction enregistrée. Doit être l'un des suivants : `view`, `like`, `share`, `comment`, `bookmark` ou `follow`.
</ParamField>

<ParamField body="target_user_id" type="string (UUID)" required>
  L'UUID de l'utilisateur dont le contenu a été consulté.
</ParamField>

<ParamField body="content_id" type="string (UUID)">
  L'UUID de l'élément de contenu spécifique avec lequel l'utilisateur a interagi. À omettre si l'interaction cible directement un profil (par exemple, un abonnement).
</ParamField>

<ParamField body="content_type" type="string">
  Le type de l'élément de contenu. Doit être l'un des suivants : `video`, `stream` ou `profile`. Requis lorsque `content_id` est fourni.
</ParamField>

<ParamField body="engagement_duration" type="number">
  Le nombre de secondes que l'utilisateur a passé à interagir avec le contenu. Utilisé pour affiner le scoring de rétention et d'affinité.
</ParamField>

<ParamField body="metadata" type="object">
  Un objet optionnel pour toute donnée contextuelle supplémentaire que vous souhaitez attacher à l'enregistrement d'interaction (par exemple, position de lecture, source de référence).
</ParamField>

## Réponse de succès

**Statut : `201 Created`**

<ResponseField name="success" type="boolean">
  `true` lorsque l'interaction a été enregistrée avec succès.
</ResponseField>

<ResponseField name="data" type="object">
  Le nouvel enregistrement d'interaction créé.

  <Expandable title="champs data">
    <ResponseField name="id" type="string (UUID)">
      L'identifiant unique de l'enregistrement d'interaction.
    </ResponseField>

    <ResponseField name="interaction_type" type="string">
      Le type d'interaction qui a été enregistré.
    </ResponseField>

    <ResponseField name="created_at" type="string (ISO 8601)">
      L'horodatage auquel l'interaction a été sauvegardée.
    </ResponseField>
  </Expandable>
</ResponseField>

## Réponses d'erreur

| Statut | Message d'erreur | Cause |
| --- | --- | --- |
| `400` | `"interaction_type et target_user_id sont requis"` | `interaction_type` ou `target_user_id` a été omis du corps de la requête. |
| `401` | `"Non authentifié"` | L'en-tête `Authorization` est manquant, expiré ou invalide. |

## Effets secondaires

<Info>
  Chaque appel réussi à cet endpoint déclenche automatiquement deux mises à jour en arrière-plan :

  1. **Métriques de rétention** : les données de rétention du créateur cible sont recalculées pour refléter le taux de visiteurs récents et le nombre total de sessions.
  2. **Score d'affinité** : le score d'affinité entre l'utilisateur spectateur et le créateur cible est mis à jour, ce qui influence la fréquence à laquelle ce créateur apparaît dans le fil de découverte du spectateur.

  Vous n'avez pas besoin d'appeler un endpoint supplémentaire pour déclencher ces mises à jour.
</Info>
