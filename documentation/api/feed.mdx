L'endpoint `discover/users` retourne une liste classée de profils de builders utilisant l'algorithme de recommandation composite XERA1 v2. Le classement combine l'historique d'engagement, les signaux de qualité créateur, la fraîcheur du contenu, la rétention de l'audience et la viralité en un seul score pour chaque profil : les builders qui apparaissent en haut sont donc réellement les plus pertinents pour l'utilisateur qui fait la requête à ce moment précis. 65% des résultats proviennent de builders vérifiés et 35% sont mis en valeur par découverte organique.

## Endpoint

```text
GET https://xera1.xyz/api/app/discover/users
```

## Authentification

<Note>
  Cet endpoint nécessite un jeton de session valide passé en tant que jeton Bearer dans l'en-tête `Authorization`.
</Note>

```text
Authorization: Bearer <session_token>
```

## Paramètres de requête

<ParamField query="limit" type="number">
  Nombre maximum de profils de builders à retourner dans une seule réponse. Utilisez ceci pour contrôler la taille de la page.
</ParamField>

<ParamField query="offset" type="number">
  Nombre de résultats à ignorer avant de retourner la page suivante. Utilisez conjointement avec `limit` pour la pagination.
</ParamField>

## Exemple de requête

<CodeGroup>

```javascript JavaScript
const response = await fetch(
  "https://xera1.xyz/api/app/discover/users?limit=20&offset=0",
  {
    method: "GET",
    headers: {
      "Authorization": "Bearer <session_token>",
    },
  }
);

const result = await response.json();
console.log(result.data.users);
```

```bash cURL
curl -G https://xera1.xyz/api/app/discover/users \
  -H "Authorization: Bearer <session_token>" \
  --data-urlencode "limit=20" \
  --data-urlencode "offset=0"
```

```python Python
import requests

response = requests.get(
    "https://xera1.xyz/api/app/discover/users",
    headers={"Authorization": "Bearer <session_token>"},
    params={"limit": 20, "offset": 0},
)

result = response.json()
print(result["data"]["users"])
```

</CodeGroup>

## Structure de la réponse

<ResponseField name="success" type="boolean">
  `true` lorsque le fil a été récupéré et classé avec succès.
</ResponseField>

<ResponseField name="algorithm" type="string">
  Toujours `"xera1-v2-composite"` : identifie l'algorithme de classement utilisé pour générer cette réponse.
</ResponseField>

<ResponseField name="cached" type="boolean">
  `true` si cette réponse a été servie depuis le cache de recommandation. Les résultats en cache sont utilisés pour les requêtes non authentifiées ou anonymes.
</ResponseField>

<ResponseField name="data" type="object">
  La charge utile du fil.

  <Expandable title="champs data">
    <ResponseField name="users" type="array">
      Un tableau d'objets de profils de builders classés.

      <Expandable title="champs de l'objet utilisateur">
        <ResponseField name="id" type="string (UUID)">
          L'identifiant unique du builder.
        </ResponseField>

        <ResponseField name="username" type="string">
          Le @handle unique du builder sur XERA1.
        </ResponseField>

        <ResponseField name="display_name" type="string">
          Le nom public d'affichage du builder.
        </ResponseField>

        <ResponseField name="avatar_url" type="string">
          URL de l'avatar du profil du builder.
        </ResponseField>

        <ResponseField name="trajectory_score" type="number">
          Un score numérique reflétant la progression globale du builder sur XERA1.
        </ResponseField>

        <ResponseField name="arc_count" type="number">
          Nombre total d'ARCs (objectifs structurés) créés par le builder.
        </ResponseField>

        <ResponseField name="last_trace_at" type="string (ISO 8601)">
          Horodatage du Trace le plus récent du builder (entrée de journal de preuve de travail).
        </ResponseField>

        <ResponseField name="is_verified" type="boolean">
          `true` si le builder dispose d'un plan d'abonnement Standard, Medium ou Pro.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Comment l'algorithme classe les builders

Le score composite XERA1 v2 combine cinq signaux pondérés pour classer chaque profil de builder :

| Signal | Poids | Ce qu'il mesure |
| --- | --- | --- |
| Engagement | 40% | Likes, commentaires, partages et abonnements reçus |
| Qualité créateur | 30% | Constances des Traces, taux de complétion des ARCs, complétude du profil |
| Fraîcheur | 15% | La récence du dernier Trace publié ou de la dernière mise à jour d'un ARC |
| Rétention | 10% | Le pourcentage de spectateurs qui reviennent sur le profil du builder |
| Viralité | 5% | Partages et portée au-delà des abonnés existants du builder |

<Info>
  Le fil réserve toujours **65% des emplacements aux builders vérifiés** (détenteurs des plans Standard, Medium ou Pro) et **35% à la découverte organique** : un mélange équilibré entre qualité et nouvelles voix.
</Info>

## Enregistrer les impressions du fil

### POST /api/app/feed/impression

Appelez cet endpoint pour chaque carte de builder que vous affichez dans le fil. Les données d'impression apprennent à l'algorithme quels profils les utilisateurs voient réellement par rapport à ceux avec lesquels ils interagissent, améliorant progressivement la qualité des recommandations futures pour cet utilisateur.

```text
POST https://xera1.xyz/api/app/feed/impression
```

**Corps de la requête**

<ParamField body="creator_id" type="string (UUID)" required>
  L'UUID du builder dont la carte a été affichée.
</ParamField>

<ParamField body="impression_type" type="string">
  Le contexte dans lequel la carte est apparue. Par défaut `"regular"` si omis.
</ParamField>

<ParamField body="position" type="number">
  La position basée sur 1 de la carte dans la liste du fil affiché. Par défaut `1` si omis.
</ParamField>

<ParamField body="recommendation_score" type="number">
  Le score composite que l'algorithme a attribué à ce builder pour cette requête. Transmettez le score pour aider à calibrer les classements futurs.
</ParamField>

<CodeGroup>

```javascript JavaScript
await fetch("https://xera1.xyz/api/app/feed/impression", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer <session_token>",
  },
  body: JSON.stringify({
    creator_id: "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    impression_type: "regular",
    position: 1,
    recommendation_score: 87.4,
  }),
});
```

```bash cURL
curl -X POST https://xera1.xyz/api/app/feed/impression \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <session_token>" \
  -d '{
    "creator_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "impression_type": "regular",
    "position": 1,
    "recommendation_score": 87.4
  }'
```

</CodeGroup>

<Tip>
  Déclenchez `POST /api/app/feed/impression` pour chaque carte de builder lorsqu'elle entre dans le viewport de l'utilisateur, pas seulement pour les cartes qui reçoivent un clic. Les données d'impression sont plus utiles lorsqu'elles reflètent précisément ce que l'utilisateur a vu, qu'il ait interagi ou non.
</Tip>
