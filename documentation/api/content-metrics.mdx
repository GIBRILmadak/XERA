Utilisez cet endpoint pour signaler comment les utilisateurs s'engagent avec du contenu spécifique sur XERA1. Le taux de complétion et la durée de visionnage ou de lecture sont deux des signaux de qualité les plus forts disponibles pour le moteur de recommandation : plus vous les signalez avec précision, mieux XERA1 peut mettre en avant le bon contenu vers le bon public. Appelez cet endpoint lorsqu'un utilisateur termine une vidéo, ferme un Trace en cours de lecture ou met une rediffusion de diffusion en direct en pause.

## Endpoint

```text
POST https://xera1.xyz/api/app/content-metrics/update
```

## Authentification

<Note>
  Cet endpoint nécessite un jeton de session valide passé en tant que jeton Bearer dans l'en-tête `Authorization`.
</Note>

```text
Authorization: Bearer <session_token>
```

## Corps de la requête

<ParamField body="content_id" type="string (UUID)" required>
  L'UUID de l'élément de contenu dont vous mettez à jour les métriques.
</ParamField>

<ParamField body="content_type" type="string" required>
  Le type de contenu signalé (par exemple, `video`, `stream`, `trace`).
</ParamField>

<ParamField body="completion_rate" type="number">
  Une décimale entre `0.0` et `1.0` représentant la quantité de contenu consommée par l'utilisateur. `0.0` signifie que rien n'a été regardé ou lu ; `1.0` signifie que l'utilisateur est arrivé à la fin.
</ParamField>

<ParamField body="engagement_duration" type="number">
  Le nombre total de secondes que l'utilisateur a passé sur cet élément de contenu pendant la session en cours.
</ParamField>

## Exemple de requête

<CodeGroup>

```javascript JavaScript
const response = await fetch(
  "https://xera1.xyz/api/app/content-metrics/update",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer <session_token>",
    },
    body: JSON.stringify({
      content_id: "f0e9d8c7-b6a5-4321-fedc-ba9876543210",
      content_type: "video",
      completion_rate: 1.0,
      engagement_duration: 142,
    }),
  }
);

const result = await response.json();
console.log(result);
```

```bash cURL
curl -X POST https://xera1.xyz/api/app/content-metrics/update \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <session_token>" \
  -d '{
    "content_id": "f0e9d8c7-b6a5-4321-fedc-ba9876543210",
    "content_type": "video",
    "completion_rate": 1.0,
    "engagement_duration": 142
  }'
```

</CodeGroup>

## Réponse de succès

**Statut : `200 OK`**

<ResponseField name="success" type="boolean">
  `true` lorsque les métriques ont été sauvegardées ou mises à jour avec succès.
</ResponseField>

<ResponseField name="data" type="object">
  L'enregistrement de métriques de contenu mis à jour pour l'utilisateur actuel et l'élément de contenu.

  <Expandable title="champs data">
    <ResponseField name="id" type="string (UUID)">
      L'identifiant unique de l'enregistrement de métriques.
    </ResponseField>

    <ResponseField name="content_id" type="string (UUID)">
      L'UUID de l'élément de contenu auquel cet enregistrement appartient.
    </ResponseField>

    <ResponseField name="content_type" type="string">
      Le type de contenu (par exemple, `video`, `stream`, `trace`).
    </ResponseField>

    <ResponseField name="completion_rate" type="number">
      Le dernier taux de complétion stocké pour cet utilisateur et cet élément de contenu.
    </ResponseField>

    <ResponseField name="avg_watch_time" type="number">
      La dernière durée d'engagement (en secondes) stockée pour cette session.
    </ResponseField>

    <ResponseField name="engagement_score" type="number">
      Un score calculé dérivé de `completion_rate` et `engagement_duration`. Utilisé en interne par le moteur de recommandation.
    </ResponseField>

    <ResponseField name="view_count" type="number">
      Le nombre total de fois où cet endpoint a été appelé pour cet élément de contenu par l'utilisateur actuel au cours de la journée en cours.
    </ResponseField>
  </Expandable>
</ResponseField>

## Cas d'usage courants

<Tabs>
  <Tab title="Vidéo terminée">
    Lorsqu'un utilisateur regarde une vidéo jusqu'au bout, envoyez `completion_rate: 1.0` avec la durée réelle en secondes.

    ```javascript
    await fetch("https://xera1.xyz/api/app/content-metrics/update", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <session_token>",
      },
      body: JSON.stringify({
        content_id: "VIDEO_UUID",
        content_type: "video",
        completion_rate: 1.0,
        engagement_duration: 180, // vidéo de 3 minutes
      }),
    });
    ```
  </Tab>
  <Tab title="Trace fermé en cours de lecture">
    Lorsqu'un utilisateur ferme un Trace après 45 secondes de lecture, omettez `completion_rate` et envoyez uniquement `engagement_duration`.

    ```javascript
    await fetch("https://xera1.xyz/api/app/content-metrics/update", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <session_token>",
      },
      body: JSON.stringify({
        content_id: "TRACE_UUID",
        content_type: "trace",
        engagement_duration: 45,
      }),
    });
    ```
  </Tab>
  <Tab title="Visionnage partiel de vidéo">
    Lorsqu'un utilisateur abandonne à mi-parcours d'une vidéo, envoyez la fraction regardée comme `completion_rate`.

    ```javascript
    await fetch("https://xera1.xyz/api/app/content-metrics/update", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <session_token>",
      },
      body: JSON.stringify({
        content_id: "VIDEO_UUID",
        content_type: "video",
        completion_rate: 0.5,
        engagement_duration: 90,
      }),
    });
    ```
  </Tab>
</Tabs>

## Comment le score d'engagement est calculé

Le serveur calcule `engagement_score` à partir de vos valeurs signalées en utilisant cette formule :

```text
engagement_score = (completion_rate × 0.6) + (min(engagement_duration / 300, 1) × 40)
```

Une session de 5 minutes (300 secondes) avec complétion totale produit le score maximum. Des sessions plus courtes ou partielles produisent des scores proportionnellement plus faibles.

<Note>
  Des taux de complétion élevés boostent directement les signaux de **fraîcheur** et de **qualité créateur** dans le moteur de recommandation. Le contenu que les utilisateurs terminent régulièrement remonte dans le fil de découverte : une récompense pour les créateurs qui produisent des ARCs, des Traces et des vidéos engageants.
</Note>

## Réponses d'erreur

| Statut | Message d'erreur | Cause |
| --- | --- | --- |
| `400` | `"content_id et content_type requis"` | `content_id` ou `content_type` a été omis du corps de la requête. |
| `401` | `"Non authentifié"` | L'en-tête `Authorization` est manquant, expiré ou invalide. |
