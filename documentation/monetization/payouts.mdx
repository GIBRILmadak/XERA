Des que vous disposez d'au moins **\$5,00** sur votre solde disponible, vous pouvez demander un retrait sur votre compte Mobile Money. XERA1 prend en charge les fournisseurs Mobile Money les plus utilises en Afrique centrale et de l'Est, et la procedure est simple : enregistrez vos coordonnees une fois, puis soumettez des demandes de retrait chaque fois que votre solde est pret. Les versements sont traites manuellement par l'equipe XERA1 et arrivent generalement sous 2 a 5 jours ouvrables.

## Methodes de versement prises en charge

| Fournisseur | Region | Delai de traitement habituel |
| --- | --- | --- |
| **Airtel Money** | Afrique centrale et de l'Est | 2 a 5 jours ouvrables |
| **Orange Money** | Afrique de l'Ouest et centrale | 2 a 5 jours ouvrables |
| **M-Pesa** | Afrique de l'Est | 2 a 5 jours ouvrables |
| **Afrimoney** | Afrique de l'Ouest | 2 a 5 jours ouvrables |
| **Autre (Mobile Money)** | Divers | 2 a 5 jours ouvrables |

<Info>
  Tous les delais de traitement sont des estimations. La vitesse reelle du transfert depend de votre operateur mobile et des conditions du reseau local.
</Info>

## Configuration de votre compte de versement

Configurez votre compte Mobile Money avant de soumettre votre premiere demande de retrait. Vous n'avez besoin de le faire qu'une seule fois : vos coordonnees sont enregistrees en toute securite et peuvent etre mises a jour a tout moment.

<Steps>
  <Step title="Aller au Tableau de bord createur → Parametres de versement">
    Ouvrez le **Tableau de bord createur** depuis le menu de votre profil. Faites defiler jusqu'a la section **Portefeuille et retraits** et localisez le panneau **Compte Mobile Money**.
  </Step>
  <Step title="Selectionner votre fournisseur Mobile Money">
    Cliquez sur le menu deroulant **Fournisseur** et choisissez l'option correspondant a votre compte : Airtel Money, Orange Money, M-Pesa, Afrimoney ou Autre.
  </Step>
  <Step title="Saisir le nom du titulaire du compte">
    Tapez le nom complet enregistre sur le compte Mobile Money dans le champ **Titulaire du compte** (par exemple : `Jean-Paul Mbeki`). Ce nom doit correspondre au compte pour eviter les transferts echoues.
  </Step>
  <Step title="Saisir votre numero de telephone Mobile Money">
    Entrez votre numero au format international dans le champ **Numero Mobile Money**. Par exemple :

    ```text
    +243810000000
    ```

    Incluez l'indicatif du pays. N'ajoutez pas d'espaces ni de tirets.
  </Step>
  <Step title="Selectionner votre code pays">
    Saisissez le code pays ISO a deux lettres dans le champ **Pays** (par exemple, `CD` pour la Republique democratique du Congo, `KE` pour le Kenya, `SN` pour le Senegal).
  </Step>
  <Step title="Enregistrer le compte">
    Cliquez sur **Enregistrer le compte**. Un message de confirmation apparait lorsque vos parametres de versement sont sauvegardes. Vous pouvez revenir modifier ces details a tout moment en cliquant sur **Modifier** dans le panneau Compte Mobile Money.
  </Step>
</Steps>

<Warning>
  Verifiez attentivement votre numero de telephone et le nom du titulaire du compte avant d'enregistrer. Si vos coordonnees de versement sont incorrectes, votre demande de retrait peut etre rejetee et vous devrez la resoumettre apres avoir corrige les parametres.
</Warning>

## Demander un retrait

Apres avoir enregistre votre compte de versement, suivez ces etapes pour demander un transfert de vos gains disponibles.

<Steps>
  <Step title="Confirmer que votre solde disponible est d'au moins $5,00">
    Verifiez la carte **Disponible pour retrait** en haut du Tableau de bord createur. Le montant affiche doit etre de **\$5,00 ou plus** pour continuer. Les gains en attente ne comptent pas dans le solde disponible.
  </Step>
  <Step title="Saisir le montant du retrait">
    Dans le panneau **Demander un retrait**, tapez le montant que vous souhaitez retirer dans le champ **Montant (USD)**. Le champ affiche votre solde disponible actuel a titre indicatif. Le retrait minimum est de **\$5,00**.

    ```text
    Minimum : $5,00
    Maximum : la totalite de votre solde disponible
    ```
  </Step>
  <Step title="Verifier et soumettre la demande">
    Verifiez le montant et confirmez que votre compte de versement enregistre s'affiche correctement. Cliquez sur **Envoyer la demande** pour soumettre. XERA1 enregistre votre demande de retrait avec un statut **En attente**.
  </Step>
  <Step title="Attendre le traitement">
    L'equipe XERA1 examine et traite les retraits manuellement. Vous recevrez une notification push chaque fois que le statut de votre retrait change. Le traitement prend generalement **2 a 5 jours ouvrables** a compter de la soumission.
  </Step>
</Steps>

## Statuts de retrait

Apres avoir soumis une demande de retrait, elle traverse les etats suivants :

<Accordion title="En attente">
  Votre demande a ete recue et est en file d'attente pour examen manuel. Aucun fond n'a encore ete transfere. Le montant est deduit de votre solde disponible pour eviter un double retrait.
</Accordion>

<Accordion title="En traitement">
  L'equipe XERA1 a approuve votre demande et execute le transfert Mobile Money. Vous recevrez une notification lorsque ce statut est defini.
</Accordion>

<Accordion title="Paye">
  Le transfert a ete effectue avec succes. Le montant est ajoute a votre total **Total verse**. Verifiez votre solde Mobile Money pour confirmer la reception.
</Accordion>

<Accordion title="Rejete">
  Le transfert n'a pas pu etre effectue. Les raisons courantes incluent un numero de telephone incorrect, un compte Mobile Money non enregistre ou un probleme reseau avec votre fournisseur. Mettez a jour vos parametres de versement et resoumettez votre demande.

  <Warning>
    Si un retrait est rejete, le montant est retourne sur votre solde disponible afin que vous puissiez le redemander apres avoir corrige les details de votre compte.
  </Warning>
</Accordion>

## Reference API

Utilisez ces points de terminaison pour gerer les parametres de versement et les demandes de retrait par programmation.

<AccordionGroup>
  <Accordion title="POST /api/monetization/payout-settings">
    Enregistre ou met a jour les coordonnees du compte Mobile Money pour le createur authentifie.

    ```bash
    POST /api/monetization/payout-settings
    Authorization: Bearer <session_token>
    Content-Type: application/json
    ```

    ```json
    {
      "provider": "airtel_money",
      "account_name": "Jean-Paul Mbeki",
      "wallet_number": "+243810000000",
      "country_code": "CD",
      "notes": "Professional account"
    }
    ```

    **Parametres du corps :**

    <ParamField body="provider" type="string" required>
      Identifiant du fournisseur Mobile Money. L'un des suivants : `airtel_money`, `orange_money`, `mpesa`, `afrimoney`, `other`.
    </ParamField>

    <ParamField body="account_name" type="string" required>
      Nom complet du titulaire du compte Mobile Money. Maximum 80 caracteres.
    </ParamField>

    <ParamField body="wallet_number" type="string" required>
      Numero de telephone Mobile Money au format international (par exemple `+243810000000`). Maximum 32 caracteres.
    </ParamField>

    <ParamField body="country_code" type="string">
      Code pays ISO 3166-1 alpha-2 a deux lettres (par exemple `CD`, `KE`). Par defaut `CD`.
    </ParamField>

    <ParamField body="notes" type="string">
      Note optionnelle pour l'equipe XERA1 (par exemple instructions de transfert speciales). Maximum 280 caracteres.
    </ParamField>

    **Reponse :**

    <ResponseField name="success" type="boolean">
      `true` lorsque les parametres de versement sont enregistres avec succes.
    </ResponseField>

    <ResponseField name="payout_method" type="object">
      L'enregistrement de la methode de versement enregistree incluant `provider`, `account_name`, `wallet_number`, `country_code` et `updated_at`.
    </ResponseField>
  </Accordion>

  <Accordion title="POST /api/monetization/withdrawals">
    Cree une nouvelle demande de retrait pour le createur authentifie.

    ```bash
    POST /api/monetization/withdrawals
    Authorization: Bearer <session_token>
    Content-Type: application/json
    ```

    ```json
    {
      "amount": 25.00
    }
    ```

    **Parametres du corps :**

    <ParamField body="amount" type="number" required>
      Montant du retrait en USD. Doit etre d'au moins `5.00` et ne pas depasser le solde disponible actuel.
    </ParamField>

    **Reponse :**

    <ResponseField name="success" type="boolean">
      `true` lorsque la demande de retrait est creee.
    </ResponseField>

    <ResponseField name="withdrawal" type="object">
      Le nouvel enregistrement de retrait avec `id`, `amount`, `status` (`pending`), `created_at` et l'instantane de la methode de versement utilisee.
    </ResponseField>

    <ResponseField name="available_balance" type="number">
      Votre solde disponible mis a jour apres que le montant du retrait a ete reserve.
    </ResponseField>
  </Accordion>
</AccordionGroup>

<Note>
  Les retraits sont traites manuellement par l'equipe XERA1. Vous recevrez une notification push sur votre appareil lorsque le statut de votre retrait passe a **En traitement** ou **Paye**. Assurez-vous que les notifications push sont activees dans votre navigateur ou dans les parametres de la PWA XERA1.
</Note>
