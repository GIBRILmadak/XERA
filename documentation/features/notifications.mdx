Les notifications XERA1 vous tiennent informés lorsque des personnes interagissent avec votre travail. Chaque like sur une Trace, nouvel abonné, pourboire entrant ou diffusion en direct d'un builder que vous suivez génère une notification pour que vous puissiez réagir sur le moment, et pas des heures plus tard. Les notifications sont diffusées à la fois dans l'application et, avec votre permission, directement sur votre appareil via push.

## Types de notifications

XERA1 génère des notifications pour les événements suivants :

| Notification | Quand elle se déclenche |
| --- | --- |
| **Nouvel abonné** | Quelqu'un commence à suivre votre profil |
| **Trace aimée** | Un builder aime l'une de vos Traces |
| **Trace commentée** | Un builder laisse un commentaire sur l'une de vos Traces |
| **Nouveau supporter (pourboire reçu)** | Un spectateur vous envoie un pourboire pendant une diffusion en direct ou via votre profil |
| **Nouvelle diffusion en direct** | Un builder que vous suivez démarre une diffusion en direct |
| **Jalon ARC atteint** | Vous complétez un jalon dans l'un de vos ARC actifs |
| **Rappel de renouvellement d'abonnement** | Votre plan d'abonnement approche de sa date de renouvellement |

<Info>
  Les notifications de diffusion en direct sont envoyées uniquement aux abonnés du streamer, et uniquement si le streamer est sur un plan payant actif (Standard, Medium ou Pro).
</Info>

## Accéder aux notifications

Cliquez sur l'**icône cloche** dans la barre de navigation pour ouvrir le panneau de notifications. La cloche affiche un badge avec votre nombre actuel de non-lus : ce nombre se met à jour en temps réel à mesure que de nouvelles notifications arrivent, pour que vous sachiez toujours quand quelque chose nécessite votre attention.

Le panneau affiche vos 50 notifications les plus récentes, triées de la plus récente à la plus ancienne. Chaque entrée affiche :

- Le type de notification et un court message
- L'avatar de l'acteur (la personne qui a déclenché la notification)
- Un horodatage relatif (par exemple, « il y a 5 min », « 2h », « il y a 3 jours »)

Cliquer sur n'importe quelle notification ouvre directement le contenu pertinent : une Trace, un stream, votre tableau de bord ARC ou vos paramètres d'abonnement, et marque la notification comme lue.

## Marquer les notifications comme lues

<Tabs>
  <Tab title="Marquer individuellement">
    Cliquez sur n'importe quelle notification dans le panneau. Elle est automatiquement marquée comme lue lorsque vous l'ouvrez, et le compteur de non-lus diminue en conséquence.
  </Tab>
  <Tab title="Tout marquer comme lu">
    Ouvrez le panneau de notifications. Toutes les notifications non lues sont marquées comme lues dès l'ouverture du panneau : vous n'avez pas besoin de cliquer sur chacune individuellement. Le badge s'efface immédiatement.
  </Tab>
</Tabs>

## Notifications push

Les notifications push permettent à XERA1 de vous alerter même lorsque l'onglet du navigateur est fermé ou que l'application est en arrière-plan. Activer les push vous donne des alertes en temps réel pour les nouveaux messages, les diffusions en direct des builders que vous suivez et les pourboires entrants.

### Activer les notifications push

<Steps>
  <Step title="Répondre à la demande de permission">
    Lors de votre première connexion, XERA1 affiche une bannière de permission en haut de l'écran : **"Activer les notifications"**. Cliquez sur **Autoriser** pour accorder la permission push.
  </Step>
  <Step title="Confirmer dans votre navigateur">
    Votre navigateur affichera sa propre boîte de dialogue de permission native. Cliquez sur **Allow** pour confirmer. Cette étape est unique.
  </Step>
  <Step title="Recevoir les alertes push">
    Une fois accordée, XERA1 enregistre votre appareil via l'API Web Push. Vous recevrez des notifications même lorsque l'application n'est pas ouverte.
  </Step>
</Steps>

<Note>
  Si vous avez fermé la demande de permission ou sélectionné **"Plus tard"**, XERA1 ne redemandera pas la permission automatiquement. Pour activer les push manuellement, allez dans les paramètres de site de votre navigateur et accordez la permission de notification pour le domaine XERA1, puis rechargez la page.
</Note>

<Warning>
  Si votre navigateur affiche **Denied** pour les notifications, XERA1 ne peut pas outrepasser ce paramètre. Vous devez supprimer le blocage dans les permissions de site de votre navigateur et recharger la page avant que la demande ne réapparaisse.
</Warning>

### Comment fonctionne la livraison push

XERA1 utilise l'**API Web Push** pour envoyer des messages push via le service push intégré de votre navigateur. Lorsqu'un événement éligible se produit : un nouveau message, une diffusion en direct d'un builder que vous suivez ou un pourboire entrant, XERA1 envoie une notification à tous les appareils enregistrés sur votre compte. Votre navigateur affiche la notification avec un titre, un résumé et une icône, même si l'onglet XERA1 est fermé.

Cliquer sur une notification push ouvre directement XERA1 sur le contenu pertinent.

## Gérer les préférences de notification

Pour contrôler les types de notifications que vous recevez, naviguez vers **Paramètres du compte → Notifications**. Chaque type de notification peut être activé ou désactivé indépendamment.

| Paramètre | Effet |
| --- | --- |
| Basculer **désactivé** | Vous ne recevez plus ce type de notification dans l'application ou via push |
| Basculer **activé** | Les notifications reprennent immédiatement pour les futurs événements |

<Tip>
  Si vous trouvez le volume des notifications de chat en direct élevé pendant les streams actifs, XERA1 supprime automatiquement les notifications de chat en direct pendant que vous visionnez ce stream : vous n'êtes donc pas alerté pour chaque message de chat pendant que vous regardez déjà.
</Tip>
