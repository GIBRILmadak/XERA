Le système de messagerie de XERA1 vous permet de vous connecter directement avec d'autres builders sur la plateforme. Que vous souhaitiez donner un retour sur la Trace de quelqu'un, proposer une collaboration sur un ARC, ou simplement contacter un builder dont la Trajectory vous a impressionné, les messages directs vous offrent un canal privé et persistant pour le faire.

## Accéder à vos messages

Cliquez sur l'icône **Messages** dans la barre de navigation principale pour ouvrir votre boîte de réception. Un badge sur l'icône indique le nombre de messages non lus dans l'ensemble de vos conversations. Le badge se met à jour en temps réel : lorsqu'un nouveau message arrive, le compte augmente immédiatement sans nécessiter de rafraîchissement de page.

<Note>
  La section Messages n'est accessible qu'aux utilisateurs connectés. Si vous n'êtes pas connecté, cliquer sur l'icône Messages vous redirige vers la page de connexion.
</Note>

## Démarrer une conversation

<Steps>
  <Step title="Trouver le profil du builder">
    Naviguez vers le profil du builder que vous souhaitez contacter. Vous pouvez accéder à un profil depuis le fil de découverte, les résultats de recherche, une carte Trace ou une page de stream.
  </Step>
  <Step title="Cliquer sur Message">
    Sur sa page de profil, appuyez ou cliquez sur le bouton **Message**. XERA1 crée automatiquement une conversation entre vous et ce builder si aucune n'existe déjà.
  </Step>
  <Step title="Écrire votre premier message">
    Saisissez votre message dans le compositeur en bas du panneau de chat. Appuyez sur **Entrée** pour envoyer, ou **Maj \+ Entrée** pour ajouter une nouvelle ligne. Vous pouvez également joindre une image ou une vidéo en utilisant le bouton **\+** à côté du champ de saisie.
  </Step>
</Steps>

## Fonctionnalités de conversation

L'interface de messagerie est divisée en deux panneaux : une liste de conversations à gauche et le chat actif à droite.

<CardGroup cols={2}>
  <Card title="Liste de conversations" icon="list">
    Tous vos fils actifs apparaissent ici, triés par activité la plus récente. Chaque fil affiche le nom de l'autre personne, un extrait de message et l'horodatage du dernier message.
  </Card>

  <Card title="Indicateurs non lus" icon="circle-dot">
    Les compteurs de messages non lus apparaissent comme des badges sur les fils individuels. Ouvrir une conversation marque automatiquement tous ses messages comme lus.
  </Card>

  <Card title="Pièces jointes média" icon="paperclip">
    Joignez des images ou des vidéos à n'importe quel message. Un aperçu s'affiche en ligne avant l'envoi, pour que vous puissiez vérifier que le fichier est correct.
  </Card>

  <Card title="Livraison en temps réel" icon="bolt">
    Les messages arrivent en temps réel. Si votre connexion tombe, XERA1 met en file d'attente les messages sortants et retente la livraison automatiquement lorsque vous vous reconnectez.
  </Card>
</CardGroup>

### Envoyer un message

Saisissez jusqu'à **4 000 caractères** par message. Pour la plupart des conversations, gardez les messages ciblés et actionnables : les builders apprécient une communication directe et substantielle plutôt que des vérifications vagues.

```text
Entrée          → Envoyer le message
Maj + Entrée    → Nouvelle ligne (messages multi-paragraphes)
Bouton +        → Joindre une image ou une vidéo
```

### Gérer une conversation

Dans n'importe quelle conversation, l'en-tête donne un accès rapide à des actions supplémentaires :

- **Supprimer** : masquer la conversation de votre liste. Elle réapparaît automatiquement si l'autre personne vous envoie un nouveau message
- **Bloquer** : empêcher les futurs messages de cet utilisateur. Vous pouvez le débloquer plus tard dans **Paramètres du compte → Confidentialité**

## Limites de messagerie

| Exigence | Détail |
| --- | --- |
| Compte requis | Vous devez être connecté pour envoyer ou recevoir des messages |
| Auto-messagerie | Vous ne pouvez pas ouvrir de conversation avec vous-même |
| Utilisateurs bloqués | Les utilisateurs bloqués ne peuvent pas vous envoyer de message ; vous ne pouvez pas envoyer de message aux utilisateurs qui vous ont bloqués |
| Types de pièces jointes | Images et vidéos uniquement |

## Cas d'usage

<Accordion title="Collaborer sur un ARC">
  Si vous souhaitez travailler avec un autre builder sur un objectif partagé, contactez-le par message direct pour vous aligner sur la portée et les jalons avant que l'un de vous ne s'engage publiquement. Un court message avec votre idée d'ARC et le rôle que vous envisagez pour lui suffit pour lancer une vraie conversation de collaboration.
</Accordion>

<Accordion title="Donner un retour sur une Trace">
  Laissez un commentaire public sur une Trace pour un retour visible. Utilisez un message direct pour une contribution plus détaillée ou privée : par exemple, si vous avez repéré un bug, avez une suggestion spécifique, ou souhaitez partager une ressource sans encombrer le fil public.
</Accordion>

<Accordion title="Discuter de rejoindre un ARC ensemble">
  Certains builders publient des ARC qui pourraient bénéficier d'un contributeur. Si vous voyez un ARC dans un domaine où vous avez des compétences pertinentes, envoyez un message au builder pour exprimer un intérêt authentique et expliquer ce que vous pourriez apporter.
</Accordion>

<Tip>
  Contactez les builders dont la Trajectory vous impressionne réellement. La communauté XERA1 valorise les approches directes et authentiques. Un message qui fait référence à une Trace ou un jalon spécifique est bien plus susceptible d'obtenir une réponse qu'un « connectons-nous » générique.
</Tip>
